# Welcome
These are my lecture materials for my class
*CS 442: Computer Graphics*
which I teach at Washington State University, Vancouver campus.

If you are a student (mine or otherwise), please use these materials freely to
learn about computer graphics.

These materials are intended to be an open educational resource. If you are a 
teacher, see the section
[Using these materials in your own classes](#using-these-materials-in-your-own-classes)
for information on how to comply with the license.
