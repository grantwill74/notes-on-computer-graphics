Notes on Computer Graphics

Samples

Samples from GitHub repo: github.com/grantwill74/notes-on-computer-graphics

  • Sample01: Init WebGPU. A blank screen cleared to a chosen color, which shows that WebGPU is enabled and able to draw to a canvas.
  • Sample02: Hello Triangle. Just what it says. A single triangle.
  • Sample03: Using vertex buffers. It doesn't visually look different from the previous sample, but behind the scenes, it's using a vertex buffer, which is important for when we want to scale up to large 3D models.
  • Sample04: Interpolation. Demonstrates how data returned from the vertex shader (in this case the color of the vertex) is automatically interpolated by the fragment shader. It's also gamma correct.
  • Sample05: A textured Quad. Demonstrates using textures and UV coordinates.
  • Sample06: Matrices. Demonstrates the use of matrices to rotate, move, stretch, and squash 3D objects when rendering.
  • Sample07: Animation. Demonstrates how to animate a model. Uses a model matrix to rotate a cube in front of another cube which was translated and scaled. Also shows the importance of winding order and depth-buffers.
  • Sample 08: A simple camera (in perspective) Renders an object in perspective for the first time. The edges of the cube recede towards the distance, like an object would appear in the real world.
  • Sample 09: Nodes and Cameras. A fully interactive scene with camera control (WASD + arrows). Demonstrates how cameras can "fly" through a scene, and how the view matrix is computed from the model matrix of the camera. Demonstrates scene objects with their own bind groups. Also demonstrates how event listening can enable keyboard controls.
  • Sample 10: Loading Meshes. Demonstrates both a procedural mesh as well as a mesh loaded from an OBJ file. Demonstrates the use of index buffers.
  • Sample 11: Hierarchical Scenes. Demonstrates hierarchical scene management. Child objects can be made to rotate around parent objects, bringing their child objects along for the ride.
  • Sample 12: Diffuse Lighting. Introduces a simple Diffuse (Lambertian) lighting shader, and the ability to visualize it on different meshes.
  • Sample 13: Phong Shading. Extends the previous sample with full Phong/Gouraud-shading support, including the optional Blinn optimization.
  • Sample 14: UV-Spheres, Cube Spheres, and Skyboxes Demonstrates two different sphere topologies: one generated using angles for easy UV mapping, the other generated from a cube for more accurate texturing. Also demonstrates cubemap textures, both with the cube sphere and with a skybox.
